# 다이어트 기록장

아이폰 화면 기준으로 만든 개인 다이어트 기록 앱. Claude Artifact로 게시해서 쓴다.

- `diet-tracker.html` — 앱 전체(마크업·스타일·스크립트) 한 파일. Artifact로 게시할 때
  `<!doctype>`·`<head>`·`<body>`가 자동으로 씌워지므로 이 파일에는 본문만 들어 있다.
  브라우저에서 직접 열려면 저 태그들로 감싸야 한다.
- 저장소: Artifact의 `db` 기능(문서 하나 = 하루, `days/YYYY-MM-DD`, 설정은 `settings/profile`).
  네트워크가 없거나 db를 못 쓰면 localStorage 캐시로 동작하고 상단에 "이 기기에만 저장"이 뜬다.

디자인: 라벤더 미스트 바탕 + 선명한 바이올렛(#5B4CF0) 강조 + 파스텔(코랄·앰버·민트·스카이).
흰 카드는 아주 옅은 그림자 한 단계만 쓰고 나머지는 여백과 색으로 정리한다.
운동 색은 클라이밍 코랄 / 러닝 앰버 / 걷기 민트 / 스트레칭 스카이, 감량은 민트·증가는 코랄.

탭: 홈 / 캘린더(일간·주간·월간) / 기록(체중·식사·운동·약·옷 핏) / 습관 / 분석

- 기본 습관 5개: 무알콜 유지 · 디카페인 · 삼시세끼 · 스트레칭 · 도시락
- 체중은 반올림하지 않는다. 입력은 0.01 단위로 받고 소수점 둘째 자리까지 그대로
  저장·표시한다(뒤의 0은 뗀다: 62.4 / 61.45 / 48). 잰 값과 잰 값끼리의 차이는
  fmtKg, 평균·추세 같은 파생 수치는 fmt1(소수점 한 자리)을 쓴다.
- 홈 체중 카드에서 바로 체중을 찍을 수 있다. 오늘 아직 안 쟀으면 입력칸이 카드 맨 위로
  올라오고, 재고 나면 숫자 아래로 내려간다. 입력칸은 렌더 대상 밖에 두어 타이핑 중
  동기화가 와도 값이 날아가지 않는다.
- 기록 탭은 날짜 입력칸이 상단에 하나뿐이다(‹ › 로 하루씩, 가운데를 눌러 달력).
  오늘이 아니면 바가 앰버색이 되고 「오늘로」가 뜬다. 캘린더에서 날짜를 눌러
  「이 날 기록하기」를 누르면 그 날짜로 맞춰진 채 기록 탭이 열린다.
- 체중 저장 전 검사: 20~300kg 밖이면 바로 거절, 최근 기록과 5kg 이상 차이나면
  한 번 되묻는다.
- 기록 목록의 항목을 누르면 수정 시트가 열린다(체중·간식·운동·약·옷 핏 각각의 필드).
  시트 안의 칩은 data-echips 로 전역 위임 처리한다.
- 진료 준비 시트: 분석 > 요약에서 열며 최근 3개월 체중·약·몸의 반응·배변·수면을 모은다.
- 끼니별 메뉴: 기록 > 식사에서 아침·점심·저녁 각각 한 줄(쉼표로 구분) + 집밥/외식/간편식.
  치는 동안은 렌더가 입력칸을 건드리지 않고, 멈추면(0.7초) 또는 포커스가 빠질 때 저장한다.
  지금까지 적은 메뉴를 빈도순으로 모아 "자주 먹은 것" 칩으로 띄우고, 마지막으로 포커스한
  칸에 넣는다. 메뉴나 종류를 넣으면 그 끼니는 자동으로 먹은 것으로 체크된다.
  외식 여부는 하루 단위 칩을 없애고 끼니 종류에서 끌어온다(예전 기록은 eatout으로 폴백).
- 몸 상태: 기록 > 체중 탭 안의 별도 카드. 식욕(없음·적음·적당·많음), 배변(못 봄/1회/2회 이상 + 상태)과
  생리(시작/중 + 양)를 누르면 그 날짜에 바로 저장된다. 위 날짜 입력을 바꾸면 그 날로 간다.
- 식욕은 GLP-1 기록의 핵심이라 분석에서 따로 다룬다: 분포, 주사 이후 날짜별 평균
  (0 없음 ~ 3 많음), 식욕 많던 날/적던 날 비교. 진료 준비 시트에도 들어간다.
- 옷 핏: 기준 옷 하나의 느낌(꽉/딱/헐렁)과 허리·엉덩이·허벅지 둘레. 체중 그래프 위에
  점으로 같이 찍히고, 생리 기간은 그래프에 음영으로 깔린다.
- 다음 주사: 마지막 투여 + 7일을 예정일로 잡아 홈에 D-day로 띄운다. 몸의 반응(메스꺼움 등)은
  약 기록에서 여러 개 고를 수 있고 분석에서 빈도로 정리된다.
- 정체 구간: 주간 평균이 3주째 0.3kg 미만으로 움직이면 분석에 원칙 8과 함께,
  그 기간에 유지된 습관·운동·삼시세끼 준수율을 보여준다.
- 주간 돌아보기: 한 주에 하나. 그 주의 요약(주 평균 변화·삼시세끼·운동·습관)을 보여주고
  기분 5단계 + "잘 지켜진 것" / "다음 주에 바꿀 것" / 메모를 남긴다. 그 주 월요일 문서의
  `review` 필드에 저장. 일요일엔 이번 주, 월요일엔 지난 주를 홈에서 권한다.
- 분석은 네 섹션(요약·체중·생활·몸)으로 나뉘고 기간(7·30·90·전체)과 따로 논다.
  요일 패턴, 하루 오르내림 폭, 월별 흐름, 조건별 비교(운동한 날/잘 잔 날/붓기/도시락),
  생리 주기 일차별 체중 편차, 기록률·연속 기록일이 들어 있다.
- 내보내기: downloads 기능으로 CSV(엑셀용, BOM 포함)와 JSON 전체 백업.
- 감량 체크포인트: 62 → 58 → 55 → 52 → 50 → 48kg, 구간마다 스스로에게 거는 말이 붙는다.
- 설정 마이그레이션: `settings.v`가 현재 버전보다 낮으면 기본 원칙·습관만 새 기본값으로
  갈아끼운다. 직접 고친 값은 그대로 둔다.
