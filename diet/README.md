# 다이어트 기록장

아이폰 화면 기준으로 만든 개인 다이어트 기록 앱. Claude Artifact로 게시해서 쓴다.

- `diet-tracker.html` — 앱 전체(마크업·스타일·스크립트) 한 파일. Artifact로 게시할 때
  `<!doctype>`·`<head>`·`<body>`가 자동으로 씌워지므로 이 파일에는 본문만 들어 있다.
  브라우저에서 직접 열려면 저 태그들로 감싸야 한다.
- 저장소: Artifact의 `db` 기능(문서 하나 = 하루, `days/YYYY-MM-DD`, 설정은 `settings/profile`).
  네트워크가 없거나 db를 못 쓰면 localStorage 캐시로 동작하고 상단에 "이 기기에만 저장"이 뜬다.

디자인: 라벤더 미스트 바탕 + 선명한 바이올렛(#5B4CF0) 강조 + 파스텔(코랄·앰버·민트·스카이).
흰 카드는 아주 옅은 그림자 한 단계만 쓰고 나머지는 여백과 색으로 정리한다.
운동 색은 클라이밍 코랄 / 러닝 앰버 / 걷기 민트 / 스트레칭 스카이, 감량은 민트·증가는 코랄.

탭: 홈 / 캘린더(일간·주간·월간) / 기록(체중·식사·운동·약·옷 핏) / 습관 / 분석

- 기본 습관 5개: 무알콜 유지 · 디카페인 · 삼시세끼 · 스트레칭 · 도시락
- 옷 핏: 기준 옷 하나의 느낌(꽉/딱/헐렁)과 허리·엉덩이·허벅지 둘레. 체중 그래프 위에
  점으로 같이 찍히고, 생리 기간은 그래프에 음영으로 깔린다.
- 다음 주사: 마지막 투여 + 7일을 예정일로 잡아 홈에 D-day로 띄운다. 몸의 반응(메스꺼움 등)은
  약 기록에서 여러 개 고를 수 있고 분석에서 빈도로 정리된다.
- 정체 구간: 주간 평균이 3주째 0.3kg 미만으로 움직이면 분석에 원칙 8과 함께,
  그 기간에 유지된 습관·운동·삼시세끼 준수율을 보여준다.
- 주간 돌아보기: 한 주에 하나. 그 주의 요약(주 평균 변화·삼시세끼·운동·습관)을 보여주고
  기분 5단계 + "잘 지켜진 것" / "다음 주에 바꿀 것" / 메모를 남긴다. 그 주 월요일 문서의
  `review` 필드에 저장. 일요일엔 이번 주, 월요일엔 지난 주를 홈에서 권한다.
- 내보내기: downloads 기능으로 CSV(엑셀용, BOM 포함)와 JSON 전체 백업.
- 감량 체크포인트: 62 → 58 → 55 → 52 → 50 → 48kg, 구간마다 스스로에게 거는 말이 붙는다.
- 설정 마이그레이션: `settings.v`가 현재 버전보다 낮으면 기본 원칙·습관만 새 기본값으로
  갈아끼운다. 직접 고친 값은 그대로 둔다.
