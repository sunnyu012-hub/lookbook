# 벡터 일러스트 제작

스톡 플랫폼은 SVG를 "사용자가 색을 마음대로 바꿔 쓰는 부품"으로 취급한다. 그래서 보기 좋은 것만으로는 통과하지 못하고, 파일 구조가 규칙을 지켜야 한다. 이 스킬은 그 규칙과, 규칙을 지키면서 그림을 망가뜨리지 않는 작업 순서를 담고 있다.

## 업로드 규칙

플랫폼별 세부 문구는 `references/platform-rules.md`에 있다. 공통되는 핵심은 일곱 가지다.

1. **배경 완전 제거** — 배경 사각형 없이 알파 투명. 피사체(인물·동물·사물)가 명확해야 한다.
2. **색상 5개 이하** — 넘으면 비슷한 계열을 하나로 통일한다.
3. **복잡하지 않은 형태** — 그라데이션·3D 음영 없이 단색 면으로만.
4. **stroke 속성 0개** — 선은 전부 면(윤곽선)으로 변환한다.
5. **`fill-rule="evenodd"` 0개** — 인쇄용 변환에서 깨진다. 삭제하되 구멍 뚫린 도형의 모양이 유지되는지 확인한다.
6. **크랙 방지** — 전체를 합집합(Unite)한 도형을 원본 뒤에 깔아 색 경계의 실선을 막는다.
7. **명암·하이라이트** — 넣는다면 흰색/검정 + 불투명도로 하고 업로드 시 색상 잠금. 완전 평면으로 그리면 잠글 색이 없어 사용성이 더 좋다. 기본은 평면.

## 작업 순서

### 1. 구성용 SVG를 스트로크로 그린다

최종 파일에는 stroke가 없어야 하지만, **그릴 때는 stroke를 쓰는 게 맞다.** 선 하나를 `M104 150 L198 55` + `stroke-width="15"`로 적는 것과, 같은 모양을 24개 좌표의 다각형으로 손으로 적는 것은 정확도가 전혀 다르다. 후자는 거의 확실히 틀어진다. 구성용 파일(`src/`)에서는 `<circle>`, `<rect rx>`, 스트로크 패스처럼 사람이 검산할 수 있는 원시 도형만 쓰고, 면으로 바꾸는 일은 스크립트에 맡긴다.

회전된 도형은 좌표축을 바꿔 계산한다. 축 방향 단위벡터 `u`와 수직 단위벡터 `v`를 잡고 `P(s,w) = O + s·u + w·v`로 꼭짓점을 뽑으면, 화살 깃이나 비스듬한 연필 같은 모양이 한 번에 맞는다. `transform="rotate(...)"`는 쓰지 않는다 — 변환이 남은 파일은 플랫폼마다 해석이 갈린다.

### 2. 파이프라인을 돌린다

```bash
python scripts/build.py src/*.svg --out final/
```

`build.py`가 순서대로 해준다.

| 스크립트 | 하는 일 |
|---|---|
| `outline.py` | stroke를 Clipper 오프셋으로 면으로 변환. 닫힌 패스·열린 패스·`fill="none"` 고리를 각각 다르게 처리하고 linecap/linejoin을 반영한다 |
| `finish.py` | `clip-path`를 실제 좌표에 구워 넣고 `<clipPath>` 제거, `fill-rule="evenodd"` 제거, 전체 합집합 백킹을 맨 뒤에 삽입 |
| `fit.py` | 알파 경계로 viewBox를 타이트하게 맞춤 |
| `check.py` | 7개 규칙 + 후처리 전후 픽셀 대조 |

`finish.py`가 evenodd를 그냥 지워도 되는 이유는 Clipper 출력이 바깥 윤곽과 구멍을 반대 방향으로 감아주기 때문이다. nonzero 규칙에서도 구멍이 그대로 유지된다. 손으로 쓴 패스에는 이 보장이 없으니, `check.py`의 전후 대조를 반드시 확인한다.

백킹 색은 면적이 가장 큰 색을 재사용한다. 새 색이 늘지 않고, 크랙이 생기더라도 이웃 색이 비쳐서 눈에 띄지 않는다.

### 3. 렌더링해서 눈으로 본다 — 생략하지 않는다

**이 단계가 이 스킬의 핵심이다.** 규칙 검사는 전부 통과하면서 그림은 완전히 망가진 상태가 아주 쉽게 나온다. 실제로 겪은 것들이다.

- 흰색(`#FFFFFF`) 몸통이 흰 배경에서 사라짐 → 큰 밝은 면은 `#EDF1F6` 같은 아주 연한 회색으로
- 화살 깃이 반대 방향을 가리켜 "과녁에 꽂힌 화살"이 "날아가는 화살"이 됨
- 노란 막대와 노란 화살표가 같은 색이라 한 덩어리로 뭉침 → 위치를 띄우거나 한쪽 색을 바꾼다
- 돋보기를 파란 막대 위에 파란색으로 올려서 사라짐 → 회색으로 바꾸고, 대신 다른 두 색을 합쳐 5색 유지

원본이 있으면 나란히 붙인 대조 시트를 만들어서 본다. 배경은 흰색도 검정도 아닌 중간 회색(`(120,124,132)` 정도)으로 깔아야 밝은 면과 어두운 면이 동시에 보인다.

```bash
python scripts/contact_sheet.py final/*.svg --ref ref/ --out compare.png
```

그리고 **그 이미지를 실제로 읽어서 확인한다.** 파일을 만들어 놓고 넘어가면 아무 의미가 없다.

### 4. 색을 5개로 줄인다

`check.py`가 색 목록을 출력한다. 넘칠 때 순서대로 시도한다.

1. **계열 통합** — 밝은 회색 두 종류, 파랑 두 종류처럼 사용자가 구분 못 할 색은 하나로. 렌즈와 받침대를 같은 `#E4E9F0`으로 합치는 식.
2. **역할 재배치** — 지우개를 빨강 대신 몸통과 같은 진한 노랑으로.
3. **요소 생략** — 원본의 작은 장식(깃대 꼭대기 금색 구슬 등)은 알아보는 데 기여하지 않으면 뺀다.

대비를 잃으면서까지 줄이지는 않는다. 서로 닿는 두 면이 같은 색이 되면 형태가 사라진다.

## 기준 팔레트

작업 중 색을 새로 뽑지 말고 여기서 고른다. 세트 전체가 한 벌로 보인다.

| 역할 | 값 |
|---|---|
| 파랑 | `#3B82F6` · 진한 `#1B57C4` · 연한 `#A9CBF0` · 아주 연한 `#CFE4FA` |
| 빨강 | `#F2555A` |
| 노랑 | `#FFC93C` · 진한 `#F0A70F` |
| 초록 | `#2FB457` |
| 회색 | `#9AA3AF` · 연한 `#E4E9F0` · 흰 대용 `#EDF1F6` |

순백 `#FFFFFF`는 큰 면에 쓰지 않는다.

## 납품

한글 파일명 zip은 Python `zipfile`로 만든다. `zip` 명령은 UTF-8 플래그를 세우지 않아 윈도우에서 이름이 깨진다.

```python
import zipfile, glob, os
with zipfile.ZipFile("icons.zip", "w", zipfile.ZIP_DEFLATED) as z:
    for f in sorted(glob.glob("final/*.svg")):
        z.write(f, os.path.basename(f))
```
