# 플랫폼 업로드 규칙 원문 정리

미리캔버스 디자인허브 기여자 가이드에서 실제로 반려 사유가 되는 항목들이다.
다른 스톡 플랫폼도 대체로 같은 내용을 요구한다.

## 요소 자체

- 주제가 명확히 드러나는 피사체(인물, 동물, 사물 등)에서 **배경이 완벽하게 제거된** 일러스트
- **색상이 5개 이하**로 사용된 일러스트
- **복잡하지 않은 형태**의 일러스트

## 색상 정리와 색상 잠금

SVG 요소는 사용자가 색을 자유롭게 바꿔 쓰는 일러스트라 색상 작업이 중요하다.

**1) 비슷한 계열의 색상 정리** — 최대 5개 색상 권장. 더 썼다면 비슷한 계열을
하나로 통일한다. 정리하지 않으면 사용성이 크게 떨어진다.

**2) 명암과 하이라이트 처리** — 여러 명도를 쓰고 싶을 때 색을 늘리지 말고:

1. 하이라이트는 흰색 `#FFFFFF`
2. 명암(그림자)은 검정 `#000000`
3. 두 색의 불투명도(Opacity)를 조절
4. 업로드 후 메타데이터 입력에서 그 흰색/검정을 **색상 잠금**

사용자가 설정할 색 가지수가 줄어들수록 사용성이 높아진다.

> 완전 평면으로 그리면 잠글 색 자체가 없어 이 항목이 자동으로 해결된다.
> 이 스킬의 기본값이 평면인 이유다.

## 크랙 방지

잘못 만들면 다운로드·인쇄 결과물에서 **크랙**(객체 색상 경계에 생기는 실선)이
보인다. 막는 방법:

1. 완성된 요소를 복제
2. 복제본을 Pathfinder → **Unite**로 하나의 오브젝트로 합침
3. 원본 요소 **뒤편에** 복제본을 깔아줌

> `finish.py`가 Clipper 합집합으로 이 과정을 자동으로 한다.

## 채우기 규칙(fill-rule)과 겹치는 도형

도형이 겹친 부분을 어떻게 채울지 결정하는 `fill-rule`에 `evenodd`가 들어 있으면
인쇄용 파일 변환에서 정상적으로 표현되지 않아 업로드가 제한된다.

1. SVG를 텍스트 편집기로 열어 `evenodd` 검색
2. 검색 결과가 없으면 그대로 업로드
3. 있으면 `fill-rule="evenodd"` 또는 `fill-rule: evenodd;` 문구 전체를 삭제
4. 저장 후 원본과 디자인이 동일한지 확인
5. 동일하면 업로드

**삭제 후 디자인이 달라졌다면** — 가운데가 뚫린 도형은 `evenodd`만 지우면
구멍이 색으로 채워질 수 있다. 이때는 안쪽 패스의 방향을 반전시키고
(Illustrator: 오브젝트 → 패스 → 패스 방향 반전) 채우기 규칙을 nonzero로 둔다.

> Clipper(pyclipper) 출력은 바깥 윤곽과 구멍의 감는 방향이 이미 반대라
> 속성만 지워도 nonzero에서 같은 모양이 나온다. `check.py --before`의
> 픽셀 대조가 이걸 확인해 준다.

> Stroke를 윤곽선으로 변환하거나 제거한 후 다시 제출해 주세요."

`stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`이 하나라도 남아
있으면 거부된다. `outline.py`가 선을 실제 면으로 바꾼다.
