# 체험단 모음 (chehumdan)

여러 체험단 사이트의 공고를 한곳에 모아 검색·분류해서 보는 공유용 웹페이지.

## 정해진 것
- 대상 사이트(1차): 리뷰노트(www.reviewnote.co.kr), 강남맛집(xn--939au0g4vj8sq.net), 레뷰(www.revu.net), 포포몬(popomon.com)
- 처음부터 공유용. 로그인·찜·개인 기록 없음 — 링크만 있으면 누구나 본다.
- 신청은 원래 사이트에서. 카드를 누르면 원문으로 이동.
- 로그인해야 보이는 정보는 수집하지 않는다. 로그인 없이 보이는 목록만 쓴다(약관·계정 정지 위험).
- 이미지·상세 본문은 복사하지 않고 제목·핵심 정보·원문 링크만 보여준다.

## 핵심 차별점 — 검색이 아니라 분류로 찾기
레퍼런스(inflexer.net)는 분류가 약해서 검색에 의존한다. 클릭만으로 좁혀지게 한다.
- 지역: 시/도 › 시/군/구 2단계. 배송형·재택은 "전국/배송"으로 분리.
- 목적: 맛집 / 카페 / 여행·숙박 / 미용·뷰티 / 생활·제품 등
- 오늘 올라온 것(처음 발견된 날 기준), 마감 임박
- 사이트별 카테고리 + 주소 + 제목 키워드("펜션", "네일", "오마카세"…)를 같이 보고 자체 기준으로 재분류.

## 구조
- `chehumdan/` 폴더, GitHub Pages로 공개.
- GitHub Actions가 하루 몇 번 수집 → JSON 생성 → 정적 페이지가 그 JSON을 읽음. 서버비 없음.

## 진행 상황
- 개발 세션의 네트워크 정책이 위 사이트들을 막고 있어 사이트 구조를 아직 확인하지 못함.
  사용자가 Allowed domains에 추가함 — 새 세션부터 적용.
- `.github/workflows/chehumdan-probe.yml`, `chehumdan/scripts/probe*` 는 구조 확인용 임시 파일.
  네트워크가 열린 세션에서는 직접 접속해서 확인하고, 이 임시 파일과 `chehumdan/_probe/` 는 삭제한다.
