# 오늘 하루

하루를 정리하고 되돌아보는 짧은 일기. 폰에서 쓰는 PWA.

> 오늘 뭐 했는지, 잘한 건 뭔지 적어두고 — 내일의 내가 읽는다.

Vite + React + TypeScript + Tailwind. 서버가 없다. 기록은 쓰는 사람의 브라우저 안에만 있다.

---

## 무엇을 적는가

화면 순서에 뜻이 있다. **사실에서 마음으로, 오늘에서 내일로** 간다.

| 칸 | 왜 있는가 |
| --- | --- |
| 오늘 기분 | 다섯 개 중 하나. 안 고르고 넘어가도 된다 |
| 오늘 뭐 했어? | 한 줄씩 담거나 태그만 눌러도 된다 — 글 쓰기 싫은 날의 기록 방법 |
| 오늘 잘한 거 | 작아도 된다. 미룬 걸 하나 한 거, 제때 잔 거 |
| 감사한 거 | 누가, 뭐가 고마웠나 |
| 내일 기대되는 거 | 아침 커피 한 잔도 기대되는 거다 |
| 내일의 나에게 | **다음에 앱을 열면 맨 위에 쪽지로 떠 있다** |
| 짧은 일기 | 한 줄이어도 충분하다 |
| 사진 | 하루 여섯 장까지. 넣을 때 작게 줄인다 |

한 칸도 필수가 아니다. 태그 하나만 누르고 닫아도 그날은 기록된 날이다.

## 되돌아보기

- **목록** — 최신 날짜부터. 적어둔 말로 찾고, 태그로 걸러낸다
- **달력** — 그 달에 쓴 날과 그날 기분이 한눈에. **빈 날을 눌러 지난 하루도 적을 수 있다**
- **사진** — 사진만 모아 보고, 거기서 그날 기록으로 바로 간다
- **그때의 오늘** — 한 달 전 · 반년 전 · 1년 전 오늘에 쓴 게 있으면 오늘 화면 아래에 한 장 뜬다

## 선

- **재촉하지 않는다.** 연속 며칠, 놓친 날 경고, 안 쓴 날 표시를 만들지 않는다.
  센 숫자는 "쌓인 하루 N일" 하나뿐이다.
- **지난 날을 막지 않는다.** 어제 못 쓴 사람이 "지난 건 못 쓰는 앱" 을 만나면 거기서 그만둔다.
- **저장 버튼이 없다.** 쓰는 동안 저장된다. 다 지운 하루는 없던 날로 돌아간다.
- **밖으로 보내지 않는다.** 서버도 로그인도 없다. 내보내기는 사람이 직접 누를 때만 파일로 나간다.

## 어디에 저장되는가

| | 어디 | 왜 |
| --- | --- | --- |
| 글 · 태그 · 기분 | `localStorage` (`oneday.entries.v1`) | 가볍고 바로 읽힌다 |
| 사진 | IndexedDB (`oneday-photos`) | localStorage 5MB 벽에 사진은 안 들어간다 |

날짜 하나에 기록 하나(`YYYY-MM-DD`, 쓰는 사람이 사는 곳의 날짜). 기록은 사진 id 만 갖고 있고
그림은 IndexedDB 에 있다 — 기록에서 빠진 그림은 앱을 켤 때 정리된다.

**브라우저 데이터를 지우거나 폰을 바꾸면 사라진다.** 그래서 설정에 내보내기가 있다.
가져오기는 덮어쓰지 않고 합치고, 같은 날짜는 나중에 고친 쪽을 남긴다.

## 돌리기

```bash
npm install
npm run dev        # 개발 서버
npm run typecheck  # tsc -b
npm test           # 날짜 · 저장 · 찾기 · 태그 · 쪽지 로직
npm run build      # dist/ (서비스 워커에 빌드 시각을 찍는다)
npm run preview
```

Vercel 에 그대로 올라간다 (`vercel.json`). 배포할 때마다 캐시 이름이 바뀌어서
폰에 옛 화면이 남지 않는다.

## 코드

```
src/
  lib/        date · storage · photos · search · tags · messages · backup   ← 순수 함수, 테스트가 붙어 있다
  hooks/      useDiary (기록 상태와 저장) · usePhotoUrl (objectURL 뒷정리)
  components/ DayEditor 가 오늘과 지난날에 똑같이 쓰인다
  screens/    TodayScreen (쓰는 곳) · LookBackScreen (보는 곳)
```

계산할 수 있는 건 저장하지 않는다 — 태그 횟수, 쌓인 일수, 쪽지는 기록에서 세고 찾는다.
