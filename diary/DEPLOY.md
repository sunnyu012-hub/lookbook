# 폰에 올리기

Vercel 에 올려서 홈 화면에 앱처럼 두는 순서다. 10분쯤 걸린다.
서버도 로그인도 없어서 준비할 게 없다.

---

## 1. Vercel 에 올리기

1. https://vercel.com 에 GitHub 계정으로 로그인한다.
2. **Add New… → Project** 에서 `sunnyu012-hub/lookbook` 을 고른다.
3. 설정에서 **Root Directory** 를 `diary` 로 바꾼다. ← 이거 하나가 제일 중요하다.
   저장소 루트에 다른 프로젝트도 같이 있어서, 그대로 두면 엉뚱한 걸 빌드한다.
4. Framework Preset 이 **Vite** 로 잡히면 그대로 둔다. 빌드 명령과 출력 폴더는
   `vercel.json` 에 이미 적혀 있다.
5. **Deploy**.

주소를 하나 받는다 (예: `https://oneday.vercel.app`).

> 아직 `main` 에 합치지 않았다면 배포 브랜치를 `claude/simple-diary-app-16h9bp`
> 로 지정하거나, 먼저 main 에 머지한다.

## 2. 홈 화면에 추가

아이폰은 **Safari** 로 열어야 한다 (크롬은 안 된다).

1. 아래 공유 버튼 → **홈 화면에 추가**
2. 이름은 `오늘 하루` 로 채워져 있다. **추가**

안드로이드 크롬은 주소창 옆 메뉴 → **앱 설치**.

이제 주소창 없이 전체화면으로 열린다.

## 3. 확인할 것

- 비행기 모드에서도 열린다 (화면을 미리 받아둔다)
- 쓰는 것도 오프라인에서 된다 — 기록은 처음부터 기기에만 저장된다

## 4. 기억할 것 하나

기록은 **그 브라우저 안에만** 있다. 주소가 바뀌거나(다른 도메인으로 옮김),
브라우저 데이터를 지우거나, 폰을 바꾸면 따라오지 않는다.

옮기는 길은 설정 안에 있다:

1. 옛 주소에서 **설정 → 파일로 내보내기** (사진까지 옮기려면 "사진도 함께" 를 켠다)
2. 새 주소에서 **설정 → 가져오기** 로 그 파일을 고른다

덮어쓰지 않고 합치고, 같은 날짜는 나중에 고친 쪽이 남는다.
