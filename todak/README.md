# 토닥토닥 숲

> 천천히 자라도 괜찮아.

아무것도 시들지 않고, 아무것도 실패하지 않는 작은 정원.
`index.html` 하나면 끝이라 빌드도 설치도 필요 없다.

## 실행

`todak/index.html` 을 브라우저에서 열면 된다. 파일을 그냥 더블클릭해도 열린다.

아이폰에서는 Safari로 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.
저장은 localStorage 라서 껐다 켜도 정원이 그대로 있다.

## 노는 법

1. 빈 흙을 누르면 **씨앗**을 심는다.
2. 물방울 표시가 뜨면 눌러서 **물**을 준다. 심고 → 물 → 새싹 → 물 → 봉오리 → 물 → 친구.
3. 피어난 **친구를 쓰다듬으면** 마음(♥)이 하나씩 쌓인다.
4. 친구를 **꾹 누르면** 숲으로 배웅한다. 배웅한 친구는 언덕 위 숲에서 계속 논다.
5. 마음으로 **자리를 넓히거나**(6 → 9 → 12칸) 등불·벤치·연못·풍경을 놓는다.

기다리는 시간은 10초 · 16초 · 22초. 서두를 일이 없다.
꺼두는 동안에도 시간은 흐르지만, 물을 안 줬다고 시드는 일은 없다.

## 안에 있는 것

- 친구 12종 (별냥이 · 반딧사슴 · 노을여우 · 눈꽃은 조금 드물다) · 도감
- 낮과 밤 전환 — 밤에는 친구들이 자고, 반딧불이가 날고, 별이 뜬다
- 물 주기 · 쓰다듬기 · 배웅에 붙는 5음계 소리 (오른쪽 아래 버튼으로 끌 수 있다)
- 꽃가루 · 반딧불이 · 하트 파티클 (canvas)

## 구조

한 파일 안에 다 있다.

- 위쪽: 하늘 · 언덕 · 나무 띠 · 밭(3열 그리드) · 아래 도구 바
- 그림은 전부 인라인 SVG 로 그린다. 캐릭터는 `creature()` 하나가 몸·귀·장식을 조합해 만든다.
- 상태는 `S` 객체 하나 (`hearts` · `slots` · `plots` · `dex` · `forest` · `decor`) → `todak-soop-v1` 키로 저장.
- 자라는 건 절대 시각(`ready`)으로만 판단해서, 탭을 닫아둬도 어긋나지 않는다.
