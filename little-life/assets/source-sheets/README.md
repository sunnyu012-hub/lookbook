# 원본 에셋 시트

여기에 받은 그림 시트(투명 PNG)를 그대로 둔다. **잘라내거나 고치지 않는다.**
개별 아이템 파일은 여기서 다시 뽑아낼 수 있어야 한다.

## 다시 뽑는 법

```bash
npm run assets:extract    # 시트를 조각내서 public/assets/collection 으로
npm run assets:manifest   # 분류 폴더로 옮기고 매니페스트 갱신
npm run assets:audit      # 빠진 것 · 깨진 경로 · 중복 점검
npm run assets:npcs       # 사람 얼굴 시트를 잘라서 public/assets/npcs 로
```

사람 얼굴 시트는 webp 로 둔다. png 로 넣으면 여섯 장이 12MB 가 되는데
webp 는 1.8MB 다 — 그림 품질 차이는 256px 로 줄여 쓰는 자리에서 안 보인다.

## 시트가 저장소에 없는 이유

시트 15장이 40MB 가까이 된다. 저장소에 넣으면 앞으로 받는 사람마다 그만큼을 내려받는다.
그래서 **개별 아이템 파일(약 5MB)만 저장소에 두고**, 원본은 여기에 넣어 쓰도록 했다.

원본을 저장소에 함께 두고 싶으면 이 폴더에 넣고 커밋하면 된다.
`.gitignore` 에서 이 폴더의 PNG 만 빼두었다.

**지금은 `extra.png` 와 `trophy.png` 두 장만 있다.** 합쳐 4MB 뿐이고 그 그림들의
유일한 사본이라 `.gitignore` 에 예외를 뒀다. 나머지 열다섯 장은 없다 — 시트가 없어도
`assets:extract` 는 있는 것만 뽑고 조용히 끝난다. 이미 뽑아둔 파일은 그대로 있으니
앱은 멀쩡하다.
어느 물건이 어느 시트 몇 번째에서 나왔는지는 `src/data/asset-manifest.json` 의
`source` · `sourceIndex` 에 남아 있다.

시트에 있었지만 아직 아무 물건에도 안 붙은 조각은 `assets/alternates/` 에 넣어뒀다.
시트가 없는 지금은 그게 그 그림들의 유일한 사본이다.

## 규칙

- 원본은 투명 PNG 그대로 둔다. 배경 제거를 다시 돌리지 않는다.
- 물건마다 흰 테두리(스티커 선)가 둘린 시트는 `PARAMS` 에 `sticker=True` 를 준다.
  그대로 두면 방에 놓았을 때 그 물건만 오려붙인 것처럼 보인다. `extra.png` 가 그렇다.
- JPEG 로 바꾸지 않는다. 알파가 사라진다.
- 시트를 새로 받으면 이름을 정하고 위 표와 `PARAMS`, 매핑 표에 한 줄씩 더한다.

### 1차 — 일상 (저장소에 있음)

1차 세 장도 투명 배경이다. 아래 설명은 흰 배경 시트가 들어올 때를 위한 것이다.
`scripts/extract-skins.py` 는 파일을 보고 알아서 정한다.

원래 흰 배경 시트라면 (다른 시트는 투명). `scripts/extract-skins.py` 가
"가장자리와 이어진 흰색" 만 지운다 — 크림색 후드와 흰 양말은 윤곽선에 둘러싸여 있어서
가장자리와 이어지지 않기 때문에 살아남는다. 전체를 밝기로 자르면 그것들까지 사라진다.

자르면서 열두 장의 **발끝을 같은 줄에, 서 있는 자리를 같은 세로선에** 맞춰
같은 크기 캔버스에 올린다. 그래서 화면에서는 그냥 같은 크기로 그리면 몸 크기가 맞는다.
우산이나 등불처럼 머리 위로 솟은 건 위쪽 여백에 그대로 들어간다.

시트가 없으면 그 모습들이 원래 캐릭터 그림으로 대신 나온다
(`CharacterSkinRenderer` 의 fallback). 깨진 그림 아이콘은 안 뜬다.
잘라낸 뒤 `?dev=skins` 로 나란히 놓고 크기를 검수한다.
