# 쓰지 않은 조각

시트에서 잘라냈지만 도감 240개 중 어느 것에도 붙지 않은 그림들이다.
**버리지 않고 여기 둔다.** 나중에 물건이 늘어나면 여기서 먼저 찾아본다.

앱은 이 폴더를 읽지 않는다. `public/` 밖이라 빌드에도 들어가지 않는다.

| 파일 | 무엇 |
| --- | --- |
| `bags-01` `bags-02` `bags-03` | 손잡이 가방 세 개 (곰 · 리본 · 구름) |
| `bags-05` `bags-06` `bags-07` | 파우치 세 개 (튤립 · 곰 · 초록 누빔) |
| `bags-12` | 분홍 체크 필통 |
| `bags-18` `bags-18-0` `bags-18-1` `bags-18-radio` | 손거울 · 라디오 · 빗 (한 덩어리로 붙어 나와서 여러 번 잘라봤다) |
| `books-16` | 분홍 펜 |

## 원본 시트는 어디에

`assets/source-sheets/` 는 비어 있다. 시트 15장이 40MB 라 저장소에 넣지 않았다.
**그래서 지금은 여기 있는 조각이 이 그림들의 유일한 사본이다.** 지우지 않는다.

시트를 다시 받으면 `assets/source-sheets/` 에 넣고 `npm run assets:extract` 로
언제든 다시 뽑을 수 있다. 이름은 그 폴더의 README 표를 따른다.
