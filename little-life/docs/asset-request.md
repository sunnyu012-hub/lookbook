# LITTLE LIFE — 그림 요청서

지금 앱에 **그림이 없어서 이모지로 자리만 채우고 있는 것이 62개**다.
(`npm run assets:audit` → `이모지 62`)

앱은 멀쩡히 돌아간다. 이모지도 못 찾으면 분류 실루엣으로 내려가는 길까지
있어서 깨지지는 않는다. 다만 방에 놓았을 때 "딸기 선반" 이 그냥 커다란
🍓 로 보인다. 그림이 오면 코드 한 줄씩만 더하면 도감·상점·방·가방이
전부 알아서 바뀐다.

---

## 1. 공통 규칙

| 항목 | 값 |
| --- | --- |
| 형식 | **투명 PNG** (배경 완전 투명, 흰 배경 금지) |
| 크기 | 물건 하나가 **긴 쪽 320px 이상**. 시트로 주면 더 커도 됨 |
| 그림자 | 바닥 그림자 **넣지 않는다** (앱이 따로 깐다) |
| 시점 | 정면에서 살짝 위 (3/4 뷰). 기존 물건들과 같은 눈높이 |
| 테두리 | 검정 아니고 **따뜻한 갈색 선**. 굵기 일정하게 |
| 채색 | 부드러운 셀셰이딩 + 옅은 광택 한 점. 파스텔, 채도 낮게 |
| 금지 | 네온 · 다크 판타지 · 두꺼운 금테 · 진한 그림자 · 과한 파티클 |

이 열세 장에서 같이 읽어야 하는 것:

- **어떤 그림에도 바닥 그림자가 없다.**
- 선은 검정이 아니라 물건 색보다 한 단계 진한 갈색이다.
- 광택은 **한 물건에 한두 점**, 왼쪽 위에서만 들어온다.
- 어떤 것도 정면으로 서 있지 않다 — 전부 살짝 위에서 내려다본 각도다.

### 시트로 주는 법 (권장)

물건을 하나씩 파일로 주는 것보다 **투명 PNG 시트 한 장**이 편하다.
자동으로 잘라내는 스크립트가 이미 있다 (`npm run assets:extract`).

- 물건끼리 **최소 40px 이상 떨어뜨린다** (붙어 있으면 한 덩어리로 잘린다)
- **왼쪽 → 오른쪽, 위 → 아래** 순서. 아래 표의 번호와 같은 순서로
- 한 줄에 몇 개를 놓든 상관없다. 줄만 눈에 띄게 나뉘면 된다
- 물건 둘레에 흰 스티커 선을 두르지 않는다 (두르면 미리 말해주면 설정으로 처리)

## 4. 받은 뒤에 하는 일 (개발 쪽)

1. 시트를 `assets/source-sheets/` 에 원본 그대로 둔다 (자르거나 고치지 않음)
2. `scripts/extract-assets.py` 에 시트 설정 한 줄 + 순서 매핑을 더한다
3. ```bash
   npm run assets:extract    # 시트를 물건별로 자른다
   npm run assets:manifest   # 분류 폴더로 옮기고 매니페스트 갱신
   npm run assets:thumbs     # 도감용 작은 그림(128px) 생성
   npm run assets:audit      # 빠진 것 · 깨진 경로 · 테두리 잘림 점검
   ```
4. `src/lib/collection/assets.ts` 의 목록에 id 를 넣는다 — **그게 전부다.**
   도감 · 상점 · 방 · 가방 · 수확 카드 · 요리 카드가 전부 알아서 바뀐다.

파일 하나씩 받아도 된다. 그 경우
`public/assets/items/<폴더>/<id>.webp` 에 직접 넣고 3~4번만 하면 된다.
폴더 이름은 위 표의 각 절에 적어뒀다.

### 지켜야 하는 것

| | |
| --- | --- |
| 원본 시트 | **1254 × 1254 · 투명 PNG · 2×2 로 네 명** (지금 받은 것과 같게) |

## UPDATE G.5 — 도시 지도 그림 한 장 · ✅ 받았다

지도 화면이 카드 목록에서 **그림 한 장 + 그 위에 얹는 상태**로 바뀌었다.
그림이 들어와서 지금은 그 지도가 뜬다. (그림이 없으면 예전 카드 목록으로
자동으로 되돌아가는 길은 그대로 둔다.)

| 항목 | 값 |
| --- | --- |
| 파일 | `public/assets/city/city_map_base.webp` ✅ |
| 크기 | **1024 × 1536** (세로 2:3). 더 커도 되지만 비율은 지킨다 |
| 형식 | webp 392KB. png 로 받아서 넣으면 3MB 가 되는데, 첫 실행에 미리 받는 파일이라 그 차이가 폰에서 기다리는 시간이 된다 |
| 결 | 부들부들 · 포근함 · 둥근 실루엣 · 파스텔 · 은은한 수채 질감 · 낮은 대비 |
| 느낌 | 시골 마을은 아니고 차가운 도심도 아닌 **부드러운 도시** |
| 금지 | 네온 · 다크 판타지 · 두꺼운 금테 · 진한 그림자 · 과한 파티클 |

### 그림에 넣지 않는 것

아래는 전부 코드가 그림 위에 얹는다. 그림에 그려 넣으면 시간이 흘러도
안 바뀌는 가짜가 하나 더 생긴다.

- 동네 이름 라벨
- 사람 얼굴
- 영업 중 / 영업 종료 같은 상태
- 새 소식 점 · 잠금 표시
- 캐릭터

### 어디에 뭐가 있어야 하는지

지금 코드가 잡고 있는 자리다 (`src/lib/city/map.ts`). 그림이 오면 이
숫자를 그림에 맞춰 미세 조정하지만, 대강의 배치가 이만큼 다르면
전부 다시 재야 한다.

| 동네 | 그림에서의 자리 |
| --- | --- |
| 초록 공원 | 왼쪽 위 (제일 넓다) |
| 오래된 채석장 | 왼쪽 맨 위 구석 — 공원에서 이어지는 돌길 끝의 작은 자리 |
| 카페 거리 | 오른쪽 위 |
| 창작 골목 | 가운데 |
| 우리 집 | 가운데 아래 |
| 밤의 거리 | 왼쪽 아래 |
| 운동 구역 | 오른쪽 아래 |

- 동네 사이는 길 · 나무 · 물가 같은 장식으로 잇는다. 그 장식은 눌리지 않는다.
- 건물 하나하나를 누르는 게 아니라 **동네 한 덩어리**가 버튼이다.
  그래서 동네끼리는 눈으로 구역이 나뉘어 보이는 게 좋다.
- 각 동네 위쪽에는 라벨 · 상태 · 얼굴 세 줄이 얹힌다.
  거기(동네 위쪽 절반)는 무늬가 복잡하지 않은 편이 읽기 좋다.
- 가장자리 여백: 위 32 · 아래 132 · 좌우 24 (아래가 넓은 건 탭 바 자리).
